# Тихие Стены — Акустический атлас

Интерактивная инженерно-архитектурная презентация по материалам двух видео:

- 3D-разрез акустической конструкции;
- физика передачи и переизлучения звука;
- чертежи узлов и лабораторных камер;
- разбор материалов и статуса доказательств;
- адаптивная компоновка для мобильных экранов.

## Публичная версия

https://leocryptus.github.io/quiet-walls-acoustic-atlas/

## Локальный запуск

```bash
python3 -m http.server 8000
```

После запуска откройте `http://127.0.0.1:8000/`.
